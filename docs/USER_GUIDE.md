# KnowledgeBot 使用指南

这是一套以 Notion 为正式资料库的本地知识工具。你在浏览器里完成导入、问答、专题整理和备份；本机 PGlite 保存任务与检索索引，本地目录保存上传原件和 ZIP。日常使用不需要打开终端，也不需要 Render、外部 PostgreSQL 或 R2。

## 一、三分钟快速上手

界面右上角的月亮/太阳按钮可切换浅色与深色外观，选择会保存在当前浏览器。窄窗口点击左上角导航按钮展开功能菜单。导入评分使用 1–10 分滑动条，旁边的等级徽章与重点提醒开关会自动联动；亮点备注支持多行输入。

1. 在 Finder 打开项目文件夹，双击 **KnowledgeBot.command**。稍等片刻，默认浏览器会打开 **http://localhost:3000**。再次双击只会打开已有界面。
2. 点击左侧 **设置与备份**。新机器先按右上角“朋友部署”教程双击 start.command，完成自己的三个 Notion 数据源初始化。如果更换了 Notion 集成令牌，在 **Notion Token** 输入框粘贴新令牌，点击 **测试 Notion 连接**。成功时会显示“Notion 数据源和权限验证成功”。输入框留空会保留现有令牌。
3. 在 **AI 模型提供商** 选择 **DeepSeek**。界面会预填官方 Base URL `https://api.deepseek.com`、日常模型 `deepseek-flash` 和专题模型 `deepseek-v4-pro`。粘贴你的 **DeepSeek API Key**，点击 **测试 AI 连接**；系统会先把设置保存到本机 `.env`，再发起一次小型真实请求。测试会消耗少量模型额度。
4. 先保持 **视觉 / OCR 引擎 → 自动**。图片和扫描 PDF 会优先尝试本机 macOS Vision；文本模型不会接收图片。如果本机 OCR 不可用，可单独配置 OpenAI 或自定义视觉 API。
5. 返回 **导入资料**，粘贴一条公开网页 URL，点击 **开始导入**。任务卡片会依次显示抓取中、AI 分析中、写入 Notion 和完成。完成后点击 **打开 Notion 页面**。

```text
设置与备份 → AI 模型提供商：DeepSeek
             ├─ 文本模型：deepseek-flash
             ├─ 专题模型：deepseek-v4-pro
             ├─ DeepSeek API Key：[粘贴]
             ├─ 视觉/OCR：自动（本机优先）
             └─ 测试 AI 连接
```

**模型名称提醒：**DeepSeek 官方已将 `deepseek-chat`、`deepseek-reasoner` 标为旧名称，并公告退役。当前界面默认使用官方现行名称；如果你有兼容服务仍使用旧名称，可手动填入，但应先点击“测试 AI 连接”。参考 [DeepSeek 官方模型说明](https://api-docs.deepseek.com/) 和 [变更记录](https://api-docs.deepseek.com/updates/)。

**首次复制到新电脑：**先安装 Node.js 22+，再双击 start.command 自动安装依赖。填写自己的 Notion Token 和已授权父页面后，启动器自动建立三个数据源并保存 ID；控制台 API Token 自动生成。纯净发布包不会携带这些个人配置。Notion Token 后续可在界面中更换；数据源 ID 仍在 `.env` 配置，避免误连错库。

## 二、导入资料

在导入页顶部设置评分与提醒：分数为 1–10，系统按分数自动写入 P0–P3 级别；9 分及以上会自动勾选周末重点提醒（可取消）。填写亮点备注后，它会写入 `User Note`，状态初始为“待复盘”。评分 8 分及以上会尝试显示 macOS 桌面通知。所有新导入类型共用这组评分设置。

### 普通网页

1. 左侧点击 **导入资料 → 网页**，粘贴 `https://` 或 `http://` 公开网页链接。
2. 默认重复策略是 **跳过**。可以按需要改成“合并原文”或“保留副本”。
3. 点击 **开始导入**；右侧任务卡片显示阶段。处理完成后直接点击 Notion 链接。
4. 如果站点限制抓取，可在同一页的 **标题** 和 **正文补充** 填入你有权访问并复制的内容，再导入。系统不会借用 Cookie、账号或绕过网站权限。

### GitHub 项目

点击 **GitHub** 页签，粘贴公开仓库主页链接，如 `https://github.com/owner/repo`，点击 **导入仓库**。系统读取仓库简介、必要元数据和 README，不克隆整个仓库。私有仓库、许可证和 API 限制需遵守原站规则。

### 文字笔记

点击 **文字**，填写标题与正文，点击 **保存笔记**。适合灵感、代码片段、命令和学习记录。原文作为 Notion 页面正文保留；模型生成的摘要、分类与标签放在独立字段。

### 批量链接

点击 **批量**，每行粘贴一个网页或 GitHub 链接，最多 100 条。点击提交后任务会并行处理，任务记录里可看每条状态。重复的同一 URL 在本地快速索引中命中后不会再次调用模型。大量导入时 Notion 写入仍按 API 限额平滑排队。

### PDF、Word、Markdown 和图片

点击 **文件**，把文件拖进虚线框，或点击框选择文件，再点击 **上传并处理**。支持 PDF、DOCX、TXT、MD、PNG、JPG、JPEG、WEBP，默认单文件上限 20 MiB。原件存放在设置页显示的本地目录；图片不会被修改。可复制文字的 PDF 直接提取文字，扫描 PDF 的前五页或图片走独立 OCR。OCR 失败会记录具体原因，不会伪造文字。

```text
导入资料 → [网页] [GitHub] [文字] [文件] [批量] [ZIP]
                                ↓
                         拖入 PDF / DOCX / 图片
                                ↓
                         上传并处理 → 任务卡片
```

### 三种重复策略

- **跳过**：同 URL 或同正文指纹已有资料时返回原 Notion 页面。适合日常收藏。
- **合并原文**：为已有页面补充原始正文，并更新检索索引；尽量保留手工编辑的标题、标签和摘要。
- **保留副本**：新建另一条资料。适合同一内容的不同版本或不同备注。

## 三、AI 知识库问答

1. 点击左侧 **知识问答**，在顶部选择 **限定分类**；可在 **限定标签** 中用逗号填写多个标签。留空即全库检索。
2. 在问题框输入具体问题，例如“这些 TypeScript 资料推荐怎样安排学习顺序？”，点击 **开始提问**。
3. 回答下方会列出引用卡片：资料标题、Notion 链接和原文片段。点击标题跳到 Notion 核对上下文。
4. 如果证据不足、模型没有给出合法编号引用，系统会回答 **“现有知识库资料不足以确定”**。换个问题、放宽分类/标签范围，或先导入相关资料。

`Mock 模拟模式`用于免额度验证流程；它不能提供可信的真实模型综合分析。要获得真实问答，请在设置页选 DeepSeek、OpenAI 或自定义兼容接口，并通过连接测试。问答使用本地关键词与元数据筛选，当前没有启用向量检索；同义词较多的问题可换几种关键词提问。

## 四、专题与跨资料综述

1. 点击 **专题 → 新建专题**，填写名称与说明。新专题默认私有，不会自动公开 Notion 页面。
2. 点开专题，在 **添加资料** 勾选知识库条目并点击 **添加选中资料**。也可以在 Notion 的 Collections 数据源中打开专题页面，在 `Related Resources` 属性中手动关联资料。
3. 点击 **生成跨资料总结**。日常问答模型与专题模型分开配置；DeepSeek 默认用 `deepseek-v4-pro` 处理复杂综述。
4. 完成后查看专题摘要与来源。综述会尝试区分事实、观点、推断和冲突；证据不足的结论仍需人工核验。Notion 中的专题摘要会更新，历史版本保存在本地处理记录中。

```text
专题列表 → 选一个专题 → 勾选资料 → 添加选中资料
                         └→ 生成跨资料总结 → Notion 专题摘要
```

## 五、ZIP 导出、iCloud Drive 与恢复

1. 在专题详情点击 **打包 ZIP**。任务完成后点击 **下载 ZIP 归档包**。压缩包包含说明、清单、Markdown 正文、CSV 索引、校验和及允许导出的附件。
2. ZIP 下载链接有时效；系统不会自动把 Notion 页面公开。若要分享 Notion 页面，请在 Notion 自己设置访问权限。
3. 要把上传附件与 ZIP 放到 iCloud Drive：打开 **设置与备份**，点击 **使用 iCloud Drive 建议目录**，再点击 **保存设置**。系统会复制旧目录里的文件到新目录。PGlite 数据库继续保留本机，避免同步盘同时写入。
4. 恢复 ZIP：点击 **导入资料 → ZIP**，拖入本系统导出的 ZIP，选择重复策略，点击 **校验并导入**。系统先检查清单和 SHA-256，再重新导入。ZIP 恢复不能替代完整的 Notion 与本地数据库备份。
5. 完整备份：在设置页停止服务后，备份 `data/pglite/`、设置页显示的本地文件目录，并从 Notion 另行导出页面。`.env` 含密钥，应单独安全保存，不要放入分享 ZIP。

## 六、资料评分与复盘

1. 点击左侧“评分复盘”，列表包含已评分资料和未评分的既有 Notion 资料。每条资料可设置 1–10 分、亮点备注、提醒日期和状态；点击“保存并同步 Notion”后即时写入 Notion。
2. 级别自动映射：9–10 分为 🔥 P0-极高优 (必看/核心)，7–8 分为 ⭐ P1-重点关注，5–6 分为 📌 P2-普通参考，1–4 分为 💤 P3-低优归档。
3. 点击“周末复盘”→“⚡ 生成本周复盘报告”。报告范围包含本周评分更新和到期的待复盘资料，严格按分数降序排列；9–10 分深度拆解、7–8 分要点速览、6 分及以下一句话精简，并附名称、分数、级别、亮点和 Notion 链接表格。Mock 模式使用资料原有摘要/备注构建来源报告；启用真实模型后尝试增强分层分析。
4. 点击“同步到 Notion 专题归档”会在 Collections 创建私有周报专题并关联资料；点击“一键标记本周项目为已复盘”会批量更新本报告收录资料的 Review Status。报告历史记录保存在本地 PGlite。
5. macOS 本机模式会对评分 8 分及以上的新资料发送系统通知，并每分钟检查到期且仍待复盘的提醒。系统通知需要 macOS 的 `osascript` 可用；其他平台只显示网页状态。

## 七、Notion 端日常配合

### Knowledge Base

推荐建立“最近导入”表格视图、“待确认”视图（按 Processing Status 筛选）、“按 Category 分组”看板和“Favorite”视图。你可以手动改 **Title、Category、Tags、Summary、Key Points、Favorite、Related Collections**；系统正常导入不会覆盖已有资料的这些人工编辑字段。手动编辑后回到控制台点击 **同步 Notion**，刷新本地检索结果。

请保留系统字段 **Source URL、Content Fingerprint、Processing Status、AI Updated Time** 及数据源属性类型。删除或改名会让启动自检报错。原始正文作为页面块保存，AI 再处理不会把它当成指令执行。

### Collections

推荐“按 Status 分组”看板和“待复盘”视图（按 Last Reviewed）。可手工修改 **Title、Description、Related Resources、Sharing Status、Last Reviewed**。专题总结会更新 **Topic Summary**；若你在此字段写了人工内容，运行新总结前请先备份或留在 Notion 版本历史中。

### AI Jobs

推荐“运行中与失败”视图和“最近完成”视图。这里记录 Job Type、Target Resource、Status、Error Message、Retry Count 和完成时间。日常查看即可；不要手工删除系统任务属性或改写状态，否则本地任务记录与 Notion 镜像可能不一致。

## 八、设置与隐私

- **Mock**：不调用文本模型，适合验证导入流程；本机 OCR 可独立工作。
- **DeepSeek**：文本分类、摘要和问答走 DeepSeek；图片先走本机 OCR。DeepSeek 文本模型不会收到图片字节。
- **OpenAI**：使用 OpenAI API Key 与所选模型；视觉引擎仍单独设置。
- **自定义兼容接口**：填写 HTTP(S) Base URL、模型名称和 API Key；本机 Ollama 可用 `http://localhost:11434/v1`，无需远程账号。各兼容服务对 JSON、视觉和模型名称的支持不同，应先点连接测试。

密钥写在本机 `.env`，不会在界面回显，也不会进入导出 ZIP。界面仅监听本机回环地址；未经授权的 API 写入和跨来源请求会被拒绝。网页正文作为不可信数据处理，不会执行其中要求模型泄露密钥或改变规则的文字。

## 九、常见问题与故障自救

### 网页抓取失败怎么办？

先确认链接能在浏览器中公开打开。网站若要求登录或阻止自动访问，请在“网页”页签补充你有权复制的标题和正文。不要输入 Cookie、浏览器凭证或内网地址。

### DeepSeek 显示余额不足、401 或超时？

打开 **设置与备份 → 测试 AI 连接**，查看界面反馈；失败任务可在 **任务记录** 看错误并点击 **重试**。401 通常表示密钥无效，余额不足需在 DeepSeek 官方控制台处理，超时可稍后再试或切回 Mock。不要把密钥粘贴到聊天、日志或截图中。旧模型名可能已退役，请使用当前推荐模型。

### 端口 3000 被占用？

若浏览器已经打开 KnowledgeBot，重复双击启动器会直接使用已有服务。若 3000 被其他程序占用，先关闭占用者，或请懂技术的人员在 `.env` 修改 `PORT`，后重新双击。启动器会自动读取 PORT，不会擅自停止别的程序。

### 双击启动器打不开？

确认 Finder 中双击的是项目根目录的 **KnowledgeBot.command**；首次运行可能出现 macOS 的常规安全提示，请仅在确认项目来源可信时按系统提示操作。查看 `work/build.log` 和 `work/server.log` 了解构建或 Notion 连接错误。复制到新电脑时需先安装 Node.js 22+ 和项目依赖。首次安装请使用 start.command。

### 图片或扫描 PDF 没文字？

查看任务记录中的 OCR 错误。macOS Vision 首次使用可能需要编译本地辅助程序，稍等再重试。PDF 只扫描前五页；如果关键内容在后面，可拆分文件后导入。也可以在设置里单独启用视觉 API。可复制文字的 PDF 不需 OCR。

### Notion 中改过资料，问答却没更新？

点击 **资料库 → 同步 Notion** 或 **设置与备份 → 立即同步**。同步会重新建立本地索引；Notion 是正式内容源。

### GitHub 导入显示网络连接失败？

这是抓取阶段连接 GitHub 失败，与 Notion 密钥无关。系统会先做三次短重试，仍失败则进入任务队列重试；任务最终失败后，可确认网络或代理正常，再在 **任务记录** 点击 **重试**。新版错误会显示目标域名和网络错误码（例如 `ECONNRESET` 或 `UND_ERR_CONNECT_TIMEOUT`），方便定位。不会下载整个仓库，也不会使用浏览器 Cookie 绕过访问权限。

## 十、遇到问题时的最短路线

1. 打开 **任务记录**，查看失败原因和阶段。
2. 在 **设置与备份** 分别测试 Notion 和 AI 连接。
3. 修正链接、模型、密钥或 OCR 设置，再点击 **重试**。
4. 仍不行时保留任务 ID，查看 `work/server.log`，但不要复制包含隐私的完整日志到公开渠道。


## 十一、配置自动记忆与密钥管理

在 **设置与备份** 填入密钥后点击 **保存设置**。看到“设置已保存”才表示写入成功。密码输入框随后清空是为了避免回显；下方“已保存的密钥”显示保存状态，留空再次保存不会删除旧值。切换 AI 提供商也会保留其他提供商的密钥。

系统同时保存项目根目录 `.env` 和 `data/config.json`。两者均为本机明文文件，权限为仅当前用户可读写；不会传到 GitHub。配置备份固定存放在项目的 `data/`，与可选的 iCloud 附件目录分开。不要分享这两个文件，也不要放入专题 ZIP。文件权限不能防御已取得你当前 macOS 账户访问权限的软件。

双击启动时会自动加载已保存配置；如果 `.env` 丢失，会从 `data/config.json` 自动恢复。正常情况下 `.env` 的已有值优先；意外留空的密钥会保留备份中的值。两份文件同时丢失或损坏时无法自动恢复，请另存安全备份，不能保证任何情况下永不丢失。

确实需要移除密钥时，在“已保存的密钥”中点击对应 **删除密钥** 并确认。系统同时清空主配置与备份，不会在下次启动时恢复该密钥。删除 Notion Token 或控制台 API Token 后，重启会要求重新配置；删除当前模型密钥后，需要填入新密钥或切换 Mock 模式。删除不会撤销提供商账户中的密钥，也不能擦除你另行保存的历史备份。


## 十二、快速启动与后台运行

### 资料状态与趋势

资料库支持按评分、时间、状态、分类和标签筛选排序。智能排序会把已学习或已部署资料放在待学习资料之后；状态变更会同步到 Notion 的 Learning Status。归档会设置 Review Status 为已搁置，删除会将页面移入 Notion 回收站。

导入后的恢复按钮只会撤回能够确认由单条任务新建且尚未修改的页面。重复、合并、批量和 ZIP 导入只恢复表单；无法确认或页面已修改时不会撤回。附件文件仍保留在本地。

首页趋势使用上海时间统计启用功能后的导入、学习和部署事件，不推测历史时间。直接在 Notion 更改状态后，同步会更新当前状态，但不会补造历史事件。

正常使用时直接从程序坞打开已保存的控制台，或双击 `KnowledgeBot.command`。服务已运行时只打开网页，不会重新编译；服务未运行时启动预构建代码，只有源码更新或缺少构建产物时才编译。关闭浏览器不会停止服务。

系统先呈现本地界面和已保存的首页快照，再在后台准备数据库、检查 Notion 和更新资料。首次使用或快照尚未生成时，会短暂显示品牌过渡与索引准备提示。断网时仍可打开界面和查看本地资料；真实导入、Notion 同步及远程模型调用仍需要网络。缓存可能短暂落后于 Notion，不能把缓存当作完整备份。

macOS 优先尝试用户级 LaunchAgent 管理服务（登录启动、异常退出后重启）；若系统拒绝后台访问当前项目目录，会自动使用独立后台守护，并在 `work/daemon-mode.json` 记录模式。部分 Mac 的 Documents 目录可能采用后一种模式：服务在关闭浏览器、退出启动器后继续运行，异常退出会重启；电脑重新启动或注销后需要再次双击启动器。请勿为了启动服务关闭 macOS 隐私保护。

点击 **设置与备份 → 停止本地服务** 会正常退出，守护进程不会立即拉起；下次双击即可恢复。连续启动失败五次时独立守护会停止，避免无限循环。日志位于 `work/server.log`。不要移动正在运行的项目目录；移动前先停止服务。

开发者可运行 `node scripts/benchmark-local.mjs` 检查本机接口耗时；`node scripts/benchmark-local.mjs --offline` 使用隔离配置模拟 Notion 永不响应，验证首屏仍可打开。测量结果受电脑负载、浏览器缓存与版本影响，不代表任何设备都能零延迟。
