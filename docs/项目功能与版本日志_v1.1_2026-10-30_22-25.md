**文档版本：** v1.1

本文整理项目目前已有功能，并提供不同长度和用途的发布日志文案。可以按场景复制使用。内容以当前源码、界面和项目文档为准。

## 项目功能概览

KnowledgeBot 是一套以 Notion 为正式资料库的个人知识管理工具。它提供中文本地图形界面，把网页、GitHub 项目、文字笔记和文件导入 Notion，并管理摘要、标签、专题、评分与复盘。开发者版默认使用 PGlite 和本地文件目录；常用操作不需要启动外部数据库或对象存储。

### 三个主要特点

1. **利用 Notion 云端同步**：正式资料与专题写入自己的 Notion 工作区，可在已登录的设备上通过 Notion 查看；本地索引、任务状态和附件仍保存在本机，需单独备份。
2. **使用 macOS 原生 OCR**：借助系统的 Vision 文字识别能力处理图片和扫描 PDF，不必为 OCR 单独注册云服务。扫描 PDF 当前最多识别前五页，首次使用可能需要安装 Apple 命令行开发者工具。
3. **双击启动，快速部署**：提供 macOS 双击启动器，自动检查运行环境、安装项目依赖并打开图形界面，无需手动安装和启动数据库。首次使用仍需 Node.js 22 或更新版本、网络连接，以及自己的 Notion 授权；真实 AI 服务还需要对应密钥。

### 资料导入与整理

- 导入公开网页、GitHub 仓库及 README、文字笔记、批量链接和文件。
- 支持 PDF、DOCX、TXT、Markdown、PNG、JPG、JPEG、WEBP；文件默认大小上限为 20 MiB。
- 网页抓取失败时可手动补充标题与正文；GitHub 导入只读取公开仓库元数据和 README，不克隆整个仓库。
- 自动生成摘要、分类、标签和要点；结构化校验 AI 输出，并计算内容指纹以识别重复资料。
- 重复资料支持跳过、合并原文或保留副本。
- 原始正文、AI 建议和用户可编辑字段分开处理；任务面板提供阶段、错误状态和重试入口。

### Notion 与 AI

- Notion 保存正式资料、专题和任务记录；启动初始化可检查并补齐所需数据源属性。
- 支持 Mock、DeepSeek、OpenAI、自定义 OpenAI 兼容接口；文本模型与 OCR/视觉引擎分开配置。
- 本机模式可使用 macOS Vision 识别图片和扫描 PDF；普通 PDF 优先提取文本层。
- 提供知识库问答、专题跨资料摘要、Notion 来源链接和证据片段。
- 当前问答主要使用标题、标签、摘要及全文关键词检索；没有启用语义向量检索。

### 评分、复盘与归档

- 资料支持 1–10 分、P0–P3 优先级、亮点备注、提醒日期和复盘状态。
- 提供到期提醒、macOS 桌面通知和按评分降序生成的周末复盘报告。
- 周报可归档到 Notion 专题，并批量标记为已复盘。
- 专题可生成 ZIP；清单、SHA-256 校验和及重复处理策略支持归档验证与重新导入。
- 导出下载使用短期签名地址；系统不会替用户公开 Notion 页面。

### 本地运行与安全

- macOS 双击 `start.command` 安装依赖、准备配置、初始化 Notion 并打开浏览器。
- 中文 Web GUI 包括导入、资料库、问答、专题、评分与复盘、任务记录、设置和使用指南。
- 设置可持久保存到本机 `.env` 与本地配置备份；密钥接口只返回配置状态，不回显密钥。
- 默认数据、任务索引和附件存放在本地；可在设置中配置 iCloud Drive 目录。
- 本地服务只监听回环地址，API 有访问令牌、同源检查、请求限流、敏感信息脱敏及 SSRF 防护。

## 发布日志文案 B：面向普通用户

### KnowledgeBot 1.0.0｜把散落资料整理成可复习的个人知识库

**三个特点**

- **资料随 Notion 云端同步**：将整理后的资料和专题保存到自己的 Notion 工作区，在其他设备上继续查看。
- **图片文字由 macOS 原生识别**：使用系统 Vision OCR 提取图片和扫描 PDF 文字，无需为 OCR 额外注册云服务。
- **双击快速启动**：启动器自动安装依赖并打开中文控制台，不需要自己搭建数据库或对象存储。

**本次带来**

- 从网页、GitHub、笔记、PDF、Word、Markdown 和图片收集资料，并将整理结果写入 Notion。
- AI 自动生成摘要、核心要点、分类与标签；重复内容可跳过、合并或保留副本。
- 在知识问答台检索已有资料，查看实际命中的 Notion 页面与引用片段。
- 创建专题并生成跨资料总结，也可以打包 ZIP 归档、校验后重新导入。
- 为资料评分并设置提醒，周末按优先级回顾本周内容。
- 通过中文图形界面管理模型、OCR、连接测试、任务状态和本地备份目录。

**开始使用**

macOS 需要安装 Node.js 22 或更新版本，准备自己的 Notion 集成令牌并授权目标父页面。之后双击 `start.command`，按向导完成首次设置。DeepSeek 等真实模型需要用户自行提供 API Key；Mock 模式可用于免模型额度验证基本流程。

**使用边界**

Notion 页面是否公开由用户自行控制。问答采用关键词与元数据检索，不保证覆盖所有语义相近的资料。扫描 PDF 的本地 OCR 目前最多处理前五页。项目当前面向个人本地使用，不包含多用户权限管理。

## 发布日志文案 C：技术 / 开发者版

### KnowledgeBot 1.0.0

**功能**

- TypeScript + Fastify API，托管中文静态 Web GUI；macOS 提供双击启动与本地后台守护。
- Notion API 数据访问层统一处理分页、重试、限流及 Schema 缓存；创建页面时合并提交页面属性与首批正文块。
- 本地默认 PGlite 持久化任务和检索索引，文件与导出归档使用本地存储；可选 PostgreSQL 与 S3 兼容对象存储配置。
- 导入流水线覆盖 URL、GitHub README、文本、文件和批量任务，使用内容指纹、AI 结果缓存和并发控制。
- LLM Provider Adapter 支持 Mock、DeepSeek、OpenAI 与自定义兼容 API；OCR/视觉配置与文本模型解耦。
- 知识问答返回实际检索资料的引用；无充分证据时不伪造引用。
- 周期复盘、Notion 归档、ZIP manifest/SHA-256 校验、下载时效签名及索引同步。
- 基础安全措施包括 Bearer Token、仅本地 GUI 会话、同源写入校验、速率限制、SSRF 地址过滤和日志脱敏。

**验证状态**

项目在开发机器上验证过本地构建、自动化测试、Notion 与 DeepSeek 连接及一次真实资料导入。新账户授权、其他 macOS 环境及真实云端部署仍应独立验收。Mock 测试不代表真实模型效果。

## 当前维护记录（尚未单独发布版本）

2026-10-30 的本地鉴权维护修复：本地 GUI 会话改为由 `API_TOKEN` 派生，使正常服务重启后现有浏览器会话不再因为随机 Cookie 变化而立即失效；令牌变化会使旧会话失效。无有效会话时，API 返回可读的刷新提示。该维护已通过类型检查、59 项自动化测试和本地受保护 API 请求验证；`package.json` 版本仍为 `1.0.0`，因此这里不把它标作已发布的 `1.0.1`。
